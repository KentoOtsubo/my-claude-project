# Quickstart: 画面遷移UI（トップ・タブ・一覧・登録編集の分割）

このガイドは、実装完了後にブラウザ上で本機能がエンドツーエンドで動作することを
検証する手順を示す。本機能はフロントエンド（`public/`）のみの変更であり、自動
テストの対象外（既存方針、`plan.md`参照）のため、以下の手動確認がテスト駆動の
代わりとなるエビデンスとなる。データ構造は[data-model.md](./data-model.md)を、
`001`〜`006`の既存機能の詳細はそれぞれのquickstart.mdを参照。

## 前提条件

- `npm install`済みであること
- `npm test`（vitest run）がすべてパスすること（バックエンドAPIは無変更のため、
  既存137件が回帰確認としてそのままパスすることを事前に確認する）
- ブラウザで`http://localhost:3000/`を開ける状態であること

## 1. サーバーを起動する

```powershell
npm run dev
```

ブラウザで`http://localhost:3000/`を開く。

## 2. User Story 1 — 迷わず目的の一覧にたどり着ける

1. 習慣を3件、進行中の目標（開始日≦本日≦終了日）を2件、事前に登録しておく
   （画面分割前の一覧・フォームで登録済みでもよい）。
2. アプリを開き直す（再読み込み）。

**期待結果**: トップページ（ホーム）に、本日未実行の習慣を対象としたリマインダー
一覧と、「習慣3件」「目標2件」の簡易サマリーが表示される（Acceptance Scenario 1）。

3. タブメニューの「習慣」を選択する。

**期待結果**: ページの再読み込みなしに習慣一覧画面へ切り替わる（Acceptance
Scenario 2、ブラウザの読み込みスピナーが出ないことを目視で確認）。

4. 続けてタブメニューの「目標」「ダッシュボード」を順に選択する。

**期待結果**: それぞれ対応する画面に切り替わる。

5. 最後にタブメニューの「ホーム」を選択する。

**期待結果**: 最新のリマインダー一覧・簡易サマリーを反映したトップページに戻る
（Acceptance Scenario 4）。

## 3. User Story 2 — 習慣を一覧から登録・編集する

1. 「習慣」タブを開き、「新規登録」ボタンを押す。

**期待結果**: 習慣登録・編集画面（新規モード）に遷移する（Acceptance Scenario 1）。

2. 名前・頻度・カテゴリを入力し、登録を実行する。

**期待結果**: 習慣一覧画面へ自動的に戻り、新しい習慣が一覧に反映されている
（Acceptance Scenario 2）。

3. 一覧のいずれかの習慣の「編集」ボタンを押す。

**期待結果**: その習慣の現在の値がフォームに反映された編集モードで表示される
（Acceptance Scenario 4）。

4. 名前を変更し、更新を実行する。

**期待結果**: 習慣一覧画面へ自動的に戻り、変更後の内容が反映されている
（Acceptance Scenario 5）。

5. 再度「新規登録」または「編集」ボタンを押し、今度はキャンセル操作を行う。

**期待結果**: 入力内容は破棄され、習慣一覧画面へ戻る。新規作成・更新は行われて
いない（Acceptance Scenario 3）。

## 4. User Story 3 — 目標を一覧から登録・編集する

User Story 2と同様の手順を「目標」タブで行う。

1. 「目標」タブ→「新規登録」→対象習慣・開始日・終了日・目標回数を入力して登録
   → 目標一覧画面へ戻り反映されていることを確認（Acceptance Scenario 1, 2）。
2. 一覧の「編集」ボタン→目標回数を変更して更新→目標一覧画面へ戻り反映されて
   いることを確認（Acceptance Scenario 4, 5）。
3. キャンセル操作で入力内容が破棄され、目標一覧画面へ戻ることを確認
   （Acceptance Scenario 3）。

## 5. User Story 4 — タブからダッシュボードを確認する

1. 習慣・チェックイン・目標が登録された状態で、「ダッシュボード」タブを選択する。

**期待結果**: `004-reports-dashboard`と同じ内容（習慣ごと・カテゴリ別の実施率、
目標の振り返り）がそのまま表示される（Acceptance Scenario 1）。

## 6. エッジケースの確認

- 習慣・目標を一件も登録していない状態でアプリを開く → トップページの簡易
  サマリーが「習慣0件」「目標0件」と表示され、リマインダー一覧は「今日の習慣は
  すべて実行済みです」と表示される（エラーにならない）。
- 登録済みだがすべて期間外（開始日が未来または終了日が過去）の目標がある状態で
  トップページを開く → 簡易サマリーの「目標数」は0件と表示される。
- 習慣登録・編集画面または目標登録・編集画面を開いた状態で、フォームを保存
  せずにタブメニューの別項目を選択する → 入力内容は破棄され、選択したタブの
  画面が表示される。

## 7. 既存機能の回帰確認

```powershell
npm test
```

**期待結果**: バックエンドAPIを変更していないため、既存の18テストファイル・
137件がすべて引き続きパスすることを確認する（デグレードがないことの確認）。

加えて、ブラウザ上で以下の既存機能が画面分割後も従来通り動作することを確認する。

- 習慣一覧のカテゴリ絞り込み（`001`）
- チェックイン履歴の表示・取り消し（`002`）
- 目標の進捗表示・達成/未達成判定（`003`）
- ダッシュボードの実施率・最長ストリーク・目標振り返り（`004`）
- リマインダーの表示有効/無効設定（`005`）
