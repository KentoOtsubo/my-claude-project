# Data Model: 画面遷移UI（トップ・タブ・一覧・登録編集の分割）

本機能はバックエンドのデータモデル（習慣・チェックイン・目標、`src/domain/`の
型定義）を一切変更しない（spec.md FR-014）。永続化されるエンティティの追加・
変更はなく、新しく生まれるのはフロントエンド上でのみ意味を持つ「画面（View）」
という表示単位のみである。

## 画面（View）

永続化されないフロントエンド上の状態。ある時点で必ずいずれか1つの画面が
「アクティブ」であり、他はすべて非表示（`hidden`）になる。

| 画面ID | 表示内容 | 遷移元 | 遷移先（操作後） |
|---|---|---|---|
| `home` | リマインダー一覧 + 簡易サマリー（習慣数・進行中の目標数） | タブ「ホーム」、アプリ起動直後の既定表示 | タブ選択で他画面へ |
| `habit-list` | 習慣一覧（カテゴリ絞り込み・チェックイン・編集・削除） | タブ「習慣」、`habit-form`からの登録/更新/キャンセル | 「新規登録」/「編集」ボタンで`habit-form`へ |
| `habit-form` | 習慣登録・編集フォーム（新規/編集モード共通） | `habit-list`の「新規登録」または「編集」ボタン | 登録・更新・キャンセルいずれも`habit-list`へ |
| `goal-list` | 目標一覧（進捗・編集・削除） | タブ「目標」、`goal-form`からの登録/更新/キャンセル | 「新規登録」/「編集」ボタンで`goal-form`へ |
| `goal-form` | 目標登録・編集フォーム（新規/編集モード共通） | `goal-list`の「新規登録」または「編集」ボタン | 登録・更新・キャンセルいずれも`goal-list`へ |
| `dashboard` | 既存`004-reports-dashboard`の表示内容 | タブ「ダッシュボード」 | タブ選択で他画面へ |

**状態遷移の制約**（FR-002, FR-006, FR-011）:

- アクティブな画面は常に1つのみ（排他的）。
- `habit-form` / `goal-form`は、対応する一覧画面（`habit-list` / `goal-list`）
  以外から直接遷移することはない（タブメニューには含まれない、`data-model.md`
  上記表の「遷移元」列の通り）。
- タブメニュー（`home` / `habit-list` / `goal-list` / `dashboard`への直接切替）は
  いつでも実行可能。`habit-form` / `goal-form`表示中にタブメニューへ切り替えた
  場合は、入力内容を破棄した上でのキャンセル操作と同様に扱う（spec.md Edge
  Cases）。

## 参照する既存エンティティ（無変更）

以下は`001`〜`006`で定義済みのバックエンドエンティティであり、本機能では
フロントエンドから既存API経由で参照するのみで、型・フィールドの変更はない。

- **習慣（Habit）**: `001-habit-management`で定義。`habit-list`・`habit-form`・
  `home`（簡易サマリーの件数集計）・`dashboard`で参照。
- **チェックイン（CheckIn）**: `002-checkin-tracking`で定義。`habit-list`・
  `home`（リマインダーのその場チェックイン）で参照。
- **目標（Goal）**: `003-goal-management`で定義。`goal-list`・`goal-form`・
  `home`（進行中の目標数の集計、`startDate <= 本日 <= endDate`でフィルタ）・
  `dashboard`で参照。
- **リマインダー一覧（ReminderList）**・**リマインダー表示設定
  （ReminderPreference）**: `005-reminders`で定義。`home`・`habit-form`
  （リマインダー表示設定チェックボックス）で参照。
